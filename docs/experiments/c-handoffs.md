| ID | 驗證問題 | 最小做法 | 通過條件 |

| C1 | 能否區分程序結束與成果完整？ | 模擬正常退出但缺少產物、結果格式錯誤、只有部分輸出。 | 不把退出成功當成交付成功；保留部分成果與明確缺口。 |
