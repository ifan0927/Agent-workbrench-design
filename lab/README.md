## 公開範圍與本機證據

2026-09-11 首次公開時，保留實驗程式、合成輸入及各組 `RESULTS.md` 摘要；各組 `results/`、E 的完整 `baseline/`、Git bundle、SQLite、原始事件及 runtime 不納入版本控制。這些資料可能包含真實專案原始碼、帳號中繼資料或本機路徑，仍留在原本的本機位置。公開文件將相關引用標記為「本機證據」；公開 clone 不包含它們，無法只靠摘要獨立重做完整歷史稽核。

真實專案名稱在公開文件中使用 `brand-frontend`、`admin-frontend`、`backend` 代稱，個人主目錄路徑已泛化。E 的來源位置可透過 `LAB_E_SOURCE` 設定，認證位置由使用者主目錄推導；公開程式不包含認證值。日期、版本、驗收數字、候選 hash 與已知限制保留原結論，E6 仍為 inconclusive。

首次公開的路徑泛化與文字匿名化發生在實驗之後；本機舊 manifest 對應當時來源，不保證符合公開版程式 hash。公開整理前的文件與程式另保存在忽略的 `.private/publication-originals/`；不能把公開版本宣稱為歷史執行時逐位元相同的版本，也不能為消除差異而重寫歷史證據。

重現 E 需要另備符合該固定 commit 與任務契約的來源、依賴 image 及本機基準／證據；它們沒有隨公開 repo 分發。既有流程測試與 audit 中部分入口也依賴本機產物。模型執行及認證操作仍按各組說明與當次授權進行，公開程式本身不提供新的執行授權。

上傳前應核對待提交檔案清單；`.gitignore` 不等同敏感資料掃描。新增結果、附件或實驗來源時，先檢查秘密、個資、原始碼及外部檔案引用，避免直接強制加入本機證據。
